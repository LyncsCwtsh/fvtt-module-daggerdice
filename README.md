# Nice more Daggerdice

![preview](images/banner.jpg?raw=true)

This module works as an addon to Dice so Nice, adding more dice faces (all d12) and a few textures to give users more customization options for their dice.

The designs are inspired by Daggerheart's domains, classes and what would make a cool looking Hope/Fear die.
Especially for textures, play around with light and dark die colours, as they will affect how it looks like.

Everything this module adds is marked with a dagger icon, so you can discern between what different DsN addons add.

### Future Plans
My final goal is to have one Hope/Fear die for every domain available.
